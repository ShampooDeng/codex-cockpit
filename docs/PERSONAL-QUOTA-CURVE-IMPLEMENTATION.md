# 独享账号额度与舒适曲线：实施记录

日期：2026-10-10（Asia/Singapore）。依据 [补充计划](PERSONAL-QUOTA-CURVE-PLAN.md) 实施。

## 已完成

- 新增本地“账号使用方式”设置：未确认、仅我使用、多人共用。绑定选定成员和生效日期；历史范围需明确选择。不同日期形成边界，同一天重新保存仅替换该边界。
- 设置通过现有 preferences 原子写入和备份机制保存。TypeScript 与 Rust 都验证声明，损坏声明集合整体回退为空，避免坏的后续边界意外恢复旧独享状态。
- 原生聚合读取返回 Codex 配置目录的不可逆摘要作为本机配置范围，不输出目录路径，不读取额外凭据。该范围及独享声明不进入同步快照。
- 新增统一的逐条额度解释：独享声明覆盖本人和日期时，直接使用有效历史账号额度参考，允许 partial，并保持其权重；不要求价格或 Token 采集成功。共享模式保留原成本分摊约束。
- 控制中心的父级曲线/热图、舒适曲线、日历和体验提醒使用相同解释。没有填写体验的日期也可展示已有的额度参考。
- 提示不再只取第一条记录。按所选成员逐条解析、按原因汇总，日历展示对应日期原因；部分记录有效时仍解释其余不可用记录。
- 原始反馈中的账号额度、体验、所属人及 cost-share-v1 快照不被独享视图覆盖；不引入虚构成本或新的同步格式。更新用量不再对有可用独享额度的记录误报“成本不足”。
- 更新用户说明。新增/扩展合成测试覆盖范围、日期、成员隔离、合法零值、部分采集、缺历史额度、原快照保留、父子组件一致性、保存及同步格式。

代码入口：`src/lib/accountUsage.ts`、`src/lib/personComfort.ts`、`src/components/AccountUsageSettings.tsx`、`PersonComfortSection.tsx`、`ComfortHistoryCalendar.tsx`、`ControlCenter.tsx`、`ComfortFeedbackPanel.tsx`、`src/App.tsx`，以及原生 `models.rs`、`local_usage.rs`、`tokei_usage.rs`。

## 使用与边界

新版中进入控制中心的“额度”页，在“谁的体验”选择本人，展开曲线下的“账号使用方式”，选择“仅我使用”，确认生效日期后应用。该入口也在“设置”页提供。仅当账号确实由该成员独享时使用此选项。

设置按本地 Codex 配置目录隔离，不能自动判断同一配置中更换了登录账号。界面明确要求换号后重置为未确认并重新确认成员与日期。历史范围按日期处理，不区分同一天内的多次账号切换；这种情况不能据此保证整天归属准确。

缺少真实历史额度参考的体验仍保留，不保证恢复所有历史曲线点。独享声明仅影响本机派生显示，其他设备不自动继承。旧版读取时可能忽略新声明，但原反馈及原成本分摊格式保持兼容。
