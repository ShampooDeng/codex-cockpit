# 本机用量与体验记录：实施记录

日期：2026-10-10（Asia/Singapore）。依据 `LOCAL-USAGE-COMFORT-HANDOFF.md` 修改，用户要求本轮不进行本地构建。

## 已修改

- `local_identity.rs` 在应用配置域保存稳定设备标识；已有同步绑定优先，兼容有效旧身份。云同步设置和采集统一读取该标识，首次加入同步不再另造设备 ID。冲突不自动迁移成员，旧本机身份的重复统计被排除并显示提示。
- `local_usage.rs` 复用现有受限采集器和日账投影，统一供用量面板、体验记录和成员设置读取；无既有快照也可接入首个本机设备。聚合缓存不含任务名称、路径或会话正文，不启用同步、不上传。重复扫描不叠加，部分扫描保留历史，失败保留旧数据；未知成本仍为 null。
- 全新本地配置通过现有成员修订协议创建“我”并关联本机。已有成员、历史反馈或明确保存的空配置不自动认领；成员设置即使没有日账也能列出本机并允许明确绑定原成员。
- 更新用量时，Token 和额度百分比独立恢复；自动回填只接受完整且改善覆盖的结果，更新修订时间而保留体验、日期、记录时间和所属人。已有完整快照不会被不可用或部分结果覆盖。
- 日历保留无百分比的体验，提供“更新用量”；曲线显示已保存数与可拟合数，并说明缺失原因。纯本地成本不用于推断共享账号的全部额度归属，未知历史百分比不填零。
